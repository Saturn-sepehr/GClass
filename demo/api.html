Programmatic API

initAnimations, initListeners, toggleAnimations, enableReducedMotion, disableReducedMotion, registerComplete, resolveHandler, defaults, animations, normalize, and the raw animation helpers

initAnimations()

Boot the engine (idempotent). Runs automatically on DOMContentLoaded in the demo bundle.

window.gclass.initAnimations()

initListeners()

Boot the engine directly; returns a teardown function.

const teardown = window.gclass.initListeners()

toggleAnimations()

Toggle on/off, persist the choice, and reload.

window.gclass.toggleAnimations()

enableReducedMotion() / disableReducedMotion()

Force animations off (persisted), or clear the forced override; then reload.

window.gclass.enableReducedMotion()
window.gclass.disableReducedMotion()

registerComplete(name, fn)

Register an onComplete handler referenced from markup via on-* -complete-<fn>.

window.gclass.registerComplete('onSpawnDone', (el) => console.log('done', el))

resolveHandler(name)

Look up an onComplete handler by name. Checks the registry first, then falls back to window[name]. Returns null if neither exists. 

window.gclass.resolveHandler('onSpawnDone') // fn | null

customAnims

Array to push your own animation definitions (see custom.html).

window.gclass.customAnims.push({ sel: '.whirl', from: { opacity: 0 }, play: (el) => ... })

defaults

Global timing / ease settings object. Inspect and override, e.g.:

console.log(window.gclass.defaults)

animations

The built-in animation definition array.

console.log(window.gclass.animations.length)

normalize(extra?)

Derive spawn / loop views of the config; optional extra definitions.

const views = window.gclass.normalize()

Animation helpers

The raw GSAP tween builders behind the utility classes are all exposed. Call them directly for one-off animations. Each returns a GSAP tween or timeline; most share a (target, delay, dur, ease) signature. 

// spawns (entrance)
SpawnV, SpawnH, spawnFade, spawnBlur, spawnSpinCW, spawnSpinCCW,
spawnXUp, spawnXDown, spawnYRight, spawnYLeft,
expandV, expandH, expandA, expandRight, expandLeft, expandUp, expandDown,
spawnClipReveal, curtainHorizontal, curtainVertical,
typewriter, countUp, countTargetVars

// loops
spinCW, spinCCW, bounce, shake, bell, pulse, radiate, hover, marquee

// mouse
verticalmove, expandmove, magnet, magnet3d, reset

// extras
flip, animatecss, finalOpacity

Example(target, vars)

A trivial helper demonstrating how to write your own: just a thin wrapper around gsap.to(). 

window.gclass.Example('.box', { x: 100, duration: 1 })
