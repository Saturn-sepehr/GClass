Custom animations

Push entries (sel / from / play / build / setup) onto window.gclass.customAnims

Definition shape

Push a config object onto window.gclass.customAnims. The engine derives a spawn (entrance) and/or loop (build) from it automatically. 

{
  sel:  ".your-class",              // the className on elements
  from: { opacity: 0, y: 20 },      // hidden state (optional)
  play: (el, delay, dur, ease) => tween | timeline,  // entrance
  build: (el, ctx) => tween | timeline,              // loop
  key:  "storageKey",               // loop storage key
  typewriter: true,                 // TextPlugin entry
  typewriterSplit: true,            // per-part typed reveal
  text: false,                      // skip the .spawn-text-* variant
  loop: false,                      // build but no auto repeat
  setup: (el, ctx) => void | teardown // special-abilities hook
}

Example: .whirl

A custom spawn that spins and fades in. The definition below is registered, and the element carries the .whirl scroll classes so it plays when scrolled into view.

whirl

Registration

Must run before initAnimations() boots the engine (i.e. before DOMContentLoaded in the demo bundle). 

window.gclass.customAnims.push({
  sel: '.whirl',
  from: { opacity: 0, rotation: 90, scale: 0.7 },
  play: (el, delay, dur, ease) =>
    window.gsap.fromTo(el, { opacity: 0, rotation: 90, scale: 0.7 },
                        { opacity: 1, rotation: 0, scale: 1,
                          duration: dur, delay, ease }),
})
