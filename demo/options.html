.ease-expo

easing to use (default "back")

expo ease
.ease-<name>

The .ease-N class passes its value straight through to GSAP, so any built-in GSAP ease works (default "back"). Common ones:

power1.in power1.out power1.inOut power2.inOut power3.out power4.out back.out elastic.out bounce.out circ.out sine.out expo.out quad.out cubic.out quart.out quint.out linear steps(12) none

Because ease- splits on -, the dots in a custom ease like power1.inOut are read as-is; only the first hyphen-separated segment is used as the name.
