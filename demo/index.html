GClass Demo

A class-driven animation library on top of GSAP. Every page below is a live documentation of one feature area - animated purely by CSS classes.

Installation

GClass is a framework-agnostic class-driven animation layer on top of GSAP. It works in vanilla JS, React, Vue, Svelte, or any bundler. 

npm install gclass-anims

Usage

Import the public API and call initAnimations() once the DOM is ready, then drop utility classes onto your markup. 

import { initAnimations } from 'gclass-anims'
initAnimations()
<div class="spawn-up">reveals sliding up on scroll</div>
<div class="float">loops a floating animation</div>
<button class="magnet click-expand">magnet + click</button>
